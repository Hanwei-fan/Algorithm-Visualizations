O(n) 求最长回文子串。先在字符间插 # 让奇偶回文统一为奇数长，再用「当前最靠右回文」的对称性，借助已算出的镜像值跳过重复扩展。

当前 i 中心 C 镜像 j=2C−i 当前回文 [C−R…R] 正在扩展
算法与转移
核心：维护「目前右端最靠右的回文」的中心 C 与右边界 R。求 p[i] 时若 i 在该回文内（i<R），它关于 C 的镜像位置 j=2C−i 的回文半径 p[j] 可以复用：p[i]=min(p[j], R−i)——这一步跳过了重复比较，是 O(n) 的关键。之后再从 p[i] 处继续中心扩展，若超过 R 就更新 C、R。
