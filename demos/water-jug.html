容器分水 · BFS / DFS

用容量 a、b 两个容器量出恰好 c 升水。把每个状态 (x,y) 看作节点、六种操作是连边：可以自己动手挑战，也可以让 BFS（最短）或 DFS（一条可行路径）自动求解。

算法
状态用二元组 (x,y) 表示两容器当前水量，初始 (0,0)。六种操作：装满A / 装满B / 倒空A / 倒空B / A倒入B / B倒入A，每个状态最多衍生 6 个新状态。BFS（队列逐层扩展）第一次到达"某容器 = c"时步数一定最短；DFS（栈/递归一条路走到底）能找到一条可行路径但不保证最短。可解的充要条件：c ≤ max(a,b) 且 c 能被 gcd(a,b) 整除。手动模式里你可以自己点操作按钮挑战，看能否用更少步数达到目标。

Mother's Milk（母亲的牛奶）

三个容量 a、b、c 的桶，初始只有第三个桶装满，反复把一个桶倒入另一个桶（倒满或倒空为止）。求当第一个桶为空时，第三个桶可能剩下的所有水量。

本演示的三桶进阶版：状态由 (x,y) 扩展到 (x,y,z)（因总量固定，实际两维即可），用 DFS/BFS 枚举所有可达状态，收集第一桶为空时第三桶的取值。掌握本页后可直接迁移。
